# طارق إف اكس V3
نسخة V3 بواجهة أقرب لمحطة تداول عربية:
- شارت شموع Canvas تفاعلي بصريًا
- فريمات 1د/5د/15د/1س/4س/1ي
- قائمة مراقبة
- شاشة أوامر شراء/بيع في وضع محاكاة فقط
- رافعة اختيارية للمحاكاة
- تحليل طارق AI
- إشارات
- أخبار
- مفضلة
- بحث وتبديل أصول

## تشغيل
npm install
npm run dev

ثم http://localhost:3000

## مهم
الشارت والأسعار في V3 الحاليان نموذج أولي محليان، وواجهة الأوامر لا ترسل أوامر حقيقية. لربط السوق الحي نحتاج WebSocket/API من مزود بيانات، ولتنفيذ التداول الحقيقي نحتاج تكامل API آمن مع منصة تداول وإدارة مفاتيح على الخادم.
